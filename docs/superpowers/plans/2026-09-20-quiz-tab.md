# 퀴즈 탭 Implementation Plan

> **For agentic workers:** 스펙은 `docs/superpowers/specs/2026-09-20-quiz-tab-design.md`.

**Goal:** study.html 의 일기 탭을 제거하고, B1 문장 1,284개를 5문장 유지 큐로 반복 출제하는 퀴즈 탭을 추가한다.

**Architecture:** 단일 HTML 파일. 회화 탭 스크립트는 그대로 두고, 퀴즈는 `window.QuizApp` IIFE 로 `#scr-quiz` 안에서만 동작한다. 순수 로직(정규화·채점·풀/큐)은 `/* TESTABLE-START */ … /* TESTABLE-END */` 마커로 감싸 node 테스트에서 추출해 검증한다.

**Tech Stack:** Vanilla JS(클래식 스크립트), localStorage, node:test.

## Global Constraints

- 외부 의존성 없음. 단일 `study.html` 로 동작해야 한다.
- 출제 레벨은 **B1 고정**, 시제 4종, 전체 주제 랜덤. 풀 1,284문장.
- 퀴즈 CSS는 전부 `#scr-quiz` 스코프.
- localStorage 키 `elab_quiz_v1` (회화 탭 `elab_progress_v1` 불변).
- 회화 탭의 기존 동작은 하나도 바뀌지 않아야 한다.
