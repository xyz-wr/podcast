# 퀴즈 탭 설계 (study.html)

작성일: 2026-09-20

## 목적

회화 탭의 문장 데이터를 이용해, 한국어 문장을 보고 영어로 작문하는 반복 퀴즈를 제공한다.
틀린 문장이 큐에 남아 계속 재출제되도록 해서 반복 학습을 통한 표현·단어 암기를 노린다.

## 탭 구성

```
[ 💬 회화 ]  [ 🎯 퀴즈 ]
```

- 기존 `일기` 탭 제거: `#scr-diary` 섹션, `window.DIARY_DATA`, `window.makeDiary`,
  `#diary-style` 블록, 하단 탭 버튼 전부 삭제
- `daily-diary.json` 파일 삭제
- `stab()` 는 `conv` / `quiz` 두 값을 처리

## 출제 범위

- **레벨 B1 고정**, **전체 주제 랜덤**
- 풀(pool) = 표현 321개 × 4시제(present/past/future/progressive) = **1,284문장**
- 각 문장의 식별자: `"<folderId>|<cardIndex>|<tense>"`
- 대표 예문(`card.example`)은 레벨 구분이 없으므로 출제에서 제외
- 주제 선택 화면 없음 — 퀴즈 탭 진입 시 바로 세션 화면

## 핵심 메커니즘: 5문장 유지 큐

```
[라운드 1]  ① ② ③ ④ ⑤        풀에서 랜덤 5문장
              ↓ 한 문제씩 카드로 5개 모두 풀이
            ②④ 정답 → 완료함으로 이동
            ①③⑤ 오답 → 큐에 잔류
              ↓ 라운드 요약 화면
[라운드 2]  ① ③ ⑤ ⑥ ⑦        오답 3 + 새 문장 2 = 항상 5문장
              ↓
[라운드 3]  ③ ⑤ ⑦ ⑧ ⑨        반복
```

규칙:

1. 큐는 항상 5문장을 유지한다. 빈 칸은 미출제 풀에서 랜덤으로 채운다.
2. 미출제 풀이 소진되면 큐가 5문장 미만이 되고, 남은 오답만 반복한다.
   큐가 비면 세션 완료.
3. 라운드마다 큐 5문장의 순서를 섞는다(위치 암기 방지).
4. 문장별로 누적 오답 횟수(`wrong`)를 기록한다.
5. 한 라운드 = 문제 카드 5개 → 라운드 요약 화면(정답 n / 오답 m, 오답 문장 목록) → 다음 라운드.

## 문제 화면

- 한국어 문장만 제시. 표현·의미·레벨·시제·주제 전부 숨김 (힌트 없음).
- 상단에 `라운드 N`, 5칸 진행 도트, `3/5`.
- 영어 입력 textarea + `확인` 버튼.

### 채점 후 화면

- 정/오 배지
- `내 답` — 모범 답안에 없는 단어는 흐리게, 빠진 핵심 단어는 표시
- `모범 답안` — 핵심 표현을 `<mark>` 하이라이트(기존 `highlightEn` 재사용), ▶ 발음 버튼
- `사실 맞았어요` 정정 버튼 / `다음` 버튼
- 정답일 때는 정정 버튼 없이 `다음`만

## 자동 채점 규칙

1. 정규화: 소문자화 → 문장부호 제거 → 축약형 확장
   (`we'll`→`we will`, `don't`→`do not`, `'s`→`is`/소유격은 유지 등 테이블 기반) → 공백 정리
2. **필수 조건**: 해당 카드의 핵심 표현 단어가 모두 포함될 것.
   기존 `exprWords()` + `variants()` 를 재사용해 어형변화를 허용한다.
3. **유사도 조건**: 모범 답안 단어 대비 일치율 80% 이상(불용어 제외 다중집합 비교).
4. 2·3 모두 만족 → 정답. 하나라도 불만족 → 오답.
5. 오답이어도 `사실 맞았어요` 를 누르면 정답 처리하고 완료함으로 이동한다.
   (이 경우에도 `wrong` 카운트는 올리지 않는다.)

## 완료함

- 세션 화면 하단 칩 `완료 N` → 완료 목록 화면
- 각 행: 한국어 / 영어 / 틀린 횟수 배지 / ▶ 발음
- `틀렸던 것만 다시 풀기` 버튼 — `wrong > 0` 인 문장만 모아 **복습 세션** 시작
  - 본 세션과 동일한 5문장 유지 큐 방식으로 진행한다.
  - 복습 세션은 완료함 구성을 바꾸지 않는다. 문장은 완료함에 그대로 남고,
    복습에서 다 맞혀도 빠지지 않으며 틀려도 본 세션 큐로 돌아가지 않는다.
  - 복습에서 틀리면 해당 문장의 `wrong` 카운트는 올라간다(실제 기록이므로).
  - 복습 세션 상태는 저장하지 않는다. 나가면 처음부터.
  - 복습 큐가 비면(전부 정답) 요약을 보여주고 완료함으로 돌아간다.

## 저장

`localStorage` 키 `elab_quiz_v1` 신규. 회화 탭의 `elab_progress_v1` 과 완전히 분리.

```js
{
  completed: { "driving-on-the-road|0|present": { wrong: 2 }, ... },
  queue:     ["driving-on-the-road|3|past", ...],   // 최대 5개, 본 세션 전용
  round:     3,
  cursor:    2                                      // 라운드 내 현재 문제 인덱스
}
```

- 앱을 껐다 켜도 진행 중 라운드부터 이어서 푼다.
- `기록 초기화` 버튼으로 전체 리셋.

## 디자인

- 회화 탭과 같은 종이질감 팔레트를 쓰되, 퀴즈 탭은 teal 계열을 주색으로 써서
  탭 전환이 시각적으로 구분되게 한다.
- 모든 신규 CSS는 `#scr-quiz` 스코프 아래에 둬서 회화 탭 스타일과 충돌하지 않게 한다.
- 기존 앱과 동일하게 단일 HTML 파일, 외부 의존성 없음, 모바일 우선.
