# 보카 탭 설계 (index.html)

작성일: 2026-10-03

## 목적

"영어 실력은 결국 단어"라는 하나의 메시지로, 회화 데이터(`conv-data`, 표현 321개)를
**① 채우기(표현 입력) → ② 꺼내기(문장으로 말하기)** 두 단계로 학습하는 탭을 index.html에 추가한다.
별도 파일(voca.html)이 아니라 기존 단일 파일 앱의 새 모듈로 넣는다.

## 위치와 구조

- 하단 탭바에 `🔤 보카` 추가 (회화 다음). `tabTo('voca')` → `VocaApp.render()`
- `<style id="voca-style">`(모두 `#screen-voca` 범위), `<section id="screen-voca">`,
  `<script id="voca-module">` IIFE → `window.VocaApp`
- 데이터는 기존 `<script id="conv-data">`를 그대로 읽는다 (중복 임베드 없음)
- 상단 세그먼트 탭: **홈 · 채우기 · 꺼내기 · 퀴즈 · 리포트**
- 저장: localStorage `elab_voca_v1` (다른 localStorage 모듈과 같은 방식, 동기화 대상 아님)

## 학습 단위

- 표현 카드 1개(`folderId|cardIndex`) = 복습 단위. 321개.
- 카드의 예문 13개 = 대표 예문 1 + 레벨 3 × 시제 4. 학습 레벨(기본 B1) 문장 4개 + 대표 예문을 돌려가며 출제.
- **빈칸 생성**: 표현을 슬롯(필수 단어 / 관사·대명사 같은 선택 단어 / `(one's)` 소유격 /
  `(oneself)` 재귀 / `(someone)` 등 와일드카드 / `(A/B)` 선택지)으로 분해하고, 어형변화
  (규칙 + 불규칙 동사표)를 허용해 문장 안에서 찾는다. 단어 사이 최대 2개의 끼어든 단어는 허용하되
  빈칸으로 만들지 않는다. 소유격·와일드카드 자리 단어는 보이게 둔다.
  못 찾은 문장은 빈칸 문제에서 제외한다.

## ① 채우기

- 세션 = 복습 예정 카드(최대 20) + 오늘의 새 표현(하루 기본 10개, 5/10/20 선택)
- 화면: 한국어 뜻 + 한국어 문장 + 영어 문장(빈칸은 글자 수만큼 폭을 가진 입력칸, 첫 글자 힌트 버튼)
- 채점: 대소문자·문장부호·축약형(we'll = we will) 무시, 나머지는 정확히 일치
- 간격 반복 단계: 5분 → 1일 → 3일 → 1주 → 2주 → 1개월 → 2개월 → 4개월
  - 새 카드 첫 시도 정답 → 3일 / 정답 → 한 단계 위 / 세션 중 틀린 적 있으면 최대 1일
  - 오답 → 0단계(5분 뒤), 세션 안에서 3장 뒤 다시 출제 + "이따 다시 물어볼게요!"
- 정답 확인 후 "예문으로 쓰임 익히기": 같은 표현 예문 전부(레벨·시제 표시, 표현 하이라이트, TTS)
- **아는 표현** = 2단계(3일) 이상

## ② 꺼내기

- **실전 회화**: 46개 폴더 = 상황. 상황 하나 = 카드 수만큼 미션(학습 레벨, 시제 랜덤).
  한국어 미션 → 영어로 입력(키보드 / 음성 인식). 힌트 1단계: 표현+뜻, 2단계: 단어 첫 글자.
  - **AI 교정 우선**: 기존 설정의 Gemini 키와 `window.gemini()`를 재사용해 판정(통과/수정 필요),
    교정 문장, 한국어 한 줄 팁("flight 뒤에 to New York을 추가해 보세요" 식)을 받는다.
    목표 표현을 쓰지 않으면 통과시키지 않도록 프롬프트에 명시.
  - **로컬 채점 대체**: 키가 없거나(`NO_KEY`) 네트워크·한도 오류 등으로 AI 교정이 불가능하면
    즉시 로컬 채점(qGrade 동일 기준)으로 판정하고 "'X' 표현을 써 보세요", "'Y'를 추가해 보세요" 식으로 교정.
    어느 쪽으로 채점했는지 피드백 말풍선에 표시한다.
- **리스닝**: 상황 선택 또는 랜덤 10문장. 재생 속도 0.7/0.85/1.0/1.2.
  영어 문장은 보여주지 않고 **듣고 단어 순서 맞추기**(퀴즈 탭 리스닝 단계와 같은 타일 UI):
  섞인 단어 타일을 들리는 순서대로 탭, 틀린 타일은 붉게 흔들리고 받지 않음(같은 단어는 글자로 비교),
  다 맞히면 표현을 하이라이트한 정답 문장 공개. 한국어 뜻 보기는 토글로 유지.
  따라 말하기(음성 인식 → 단어별 일치 표시)는 순서를 맞추기 전에는 점수만 보여준다
  (인식된 문장이 곧 정답이라서). 미지원 브라우저는 안내 문구.

## 퀴즈

- **1분 퀴즈**: 60초, 빈칸 4지선다(오답 보기는 같은 시제의 다른 표현 빈칸). 최고 기록 저장,
  틀린 표현을 복습 대기로 보내기.
- 주간 리그는 넣었다가 제거(2026-10-03, 사용자 요청). 서버가 없어 가상 봇과의 경쟁만 가능했다.
- XP는 학습량 지표로만 남긴다: 채우기 정답 10·오답 2, 미션 통과 15(재시도 통과 8), 리스닝 3,
  퀴즈 정답 5, 레벨 테스트 20.

## 리포트

- 아는 표현 / 321, 오늘 학습 시간, 연속 학습일, 이번 주 XP
- 아는 표현 증가 선 그래프(일별 스냅숏), 최근 7일 학습 시간 막대, 복습 단계 분포
- **레벨 테스트**: A2·B1·B2 각 5문항 빈칸 타이핑(첫 글자 힌트) → 예상 아는 표현 수, 추정 레벨,
  이전 테스트와 비교. 맞힌 표현을 '아는 표현'으로 표시할지 선택.
- **문법(시제) 약점**: 채우기·회화에서 시제별 정답/오답 집계 → 틀린 시제만 골라 핵심 설명 카드 +
  오답 노트(최근 60개).
